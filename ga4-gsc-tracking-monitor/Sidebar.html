4. Rules (advanced)

Property names containing "old", "test", "staging" or "do not use" start as Monitor? = No.
How red / amber is decided
  • 🔴 No access / Access removed: the reporting account can't read the property or no longer sees it (e.g. a client removed it, or Search Console verification was lost).
  • 🔴 Not tracking: 0 sessions in the last 7 days when there used to be data.
  • 🔴 Tracking drop: sessions fell by the red % vs normal. Tracking rarely drops to zero after a migration; usually a few pages keep the tag, so a big drop is the key signal.
  • 🔴 Under-tracking: GA4 shows fewer sessions than Google search clicks alone for the same site.
  • 🟠 Traffic drop: GA4 and search clicks fell together. Probably real traffic, not a tracking fault.
  • 🟠 Data gaps / Dropping / Tag not found / Different tag: worth a look, not urgent.
  • While a drop stays open, the script compares against the last healthy level ("Normal weekly level"), so a long outage never starts to look normal.
  • Set Monitor? = No on old, test or duplicate properties. They stay listed with their numbers but never alert.
